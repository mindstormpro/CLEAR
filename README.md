# CLEAR!
clear is a tactical turn-based strategy game where you clear rooms of a level one-by-one by controlling the actions each squadmate makes.  
Oh yeah, There's also wizards and fox people.

Cool/notable features:
 - Clearing of rooms
 - Tactical stuff
 - Replay mode (?) where you can watch your squad replay a level in real time instead of turn-by-turn (you have to actually beat the level first tho)
 - ARCO inspired skill tree (?)
 - Diora inspired 3D Graphix for Max Koolness!!!
